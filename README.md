# Computer Vision Lab

Coursework and experiments for the Computer Vision Lab.

## Contents

- Lab 1: RGB and grayscale image processing
- Lab 2: Image processing exercises
- Lab 3: Noise reduction and filtering
- Lab 4: Additional image processing exercises
- Lab 5: Image analysis experiments
- Lab 6: Computer vision exercises
- Lab 7: Harris corner detector
- Lab 8: SIFT feature detection and matching

The repository includes Python scripts, Jupyter notebooks, lecture materials, reports, and sample images.
